# ✈️ Smart Airline Reservation System

A production-inspired Airline Reservation System developed using FastAPI, MySQL, JWT Authentication, QR/PDF Ticket Generation and Gmail Email Integration.

---

## 📌 Project Overview

Smart Airline Reservation System is a backend application that allows users to register, login, search flights, book tickets, manage bookings, generate tickets, receive email notifications and track flight status.

The system includes authentication, authorization, booking workflows, waitlist management, refund processing, analytics and ticket generation functionalities inspired by real airline reservation platforms.

---
